# 기획·설계 요약 (Hindsight)

## 아이디어 선정
후보 10개를 비교했습니다: 판단 일지(Hindsight), 회의록 액션아이템 추적기, 이력서 버전 관리, 구독료 트래커, 스터디 간격반복, 로그 뷰어, 독서 노트, 습관 트래커, 프리랜서 인보이스, 링크 아카이브.
Hindsight를 선택한 이유: (1) 외부 API 없이 핵심 가치(보정 피드백)를 완전히 구현 가능, (2) 단일 SQLite로 저비용 운영, (3) 습관/노트류 대비 "결과를 나중에 채점한다"는 차별점. 점수 산정은 가중 평가표를 정식으로 기록하지 않고 정성 비교로 결정했습니다.
시장 조사는 웹 검색을 수행하지 않았습니다(검증되지 않은 경쟁 서비스 정보는 기재하지 않음).

## PRD 요약
- 사용자: 반복적으로 중요한 판단을 내리고 그 품질을 개선하고 싶은 개인(PM, 투자자, 창업자 등)
- 흐름: 가입 → 결정+예측+확신도 기록 → 검토일 도래 → 결과 기록 → 통계로 보정 확인
- 수용 기준: 위 흐름이 새로고침 후에도 유지되고, 타 사용자 데이터에 접근 불가, 잘못된 입력은 명확한 오류 표시

## 아키텍처
Browser → Next.js route handlers → 비즈니스 로직(`src/lib`) → SQLite(`node:sqlite`).
테이블: `users`, `sessions`(토큰 SHA-256 해시 저장, 30일 만료), `decisions`(user_id FK, confidence CHECK 1–99, outcome CHECK 0/1/NULL). 모든 쿼리는 `user_id`로 한정.
Brier = mean((confidence/100 − outcome)²). 보정 구간: 1–20/21–40/41–60/61–80/81–99.
